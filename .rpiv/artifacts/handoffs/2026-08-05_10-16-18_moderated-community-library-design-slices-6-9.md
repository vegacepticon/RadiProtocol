## Learnings
- **Artifact edit corruption (CRITICAL, still applies):** When using the `edit` tool on the design artifact, unicode escapes (`\u003e`/`\u003c`/`\u0026`) in `newText` were sometimes persisted as literal 6-char strings instead of decoding to `>`/`<`/`&`, corrupting generics (`Promise<string>`) and `&&`. **Always write actual `<`/`>`/`&` characters in `newText`, and ALWAYS re-read the persisted fence after every edit** (`awk '/### <file>/{f=1} f{print} f&&/^```$/{c++; if(c==2)exit}' <artifact> | grep -cE "u003e|u003c|u0026"` must return 0). The slice-verifier sees correctly-decoded code in its prompt and does NOT verify the persisted artifact — corruption is invisible to it. This session hit ZERO corruption by always re-reading + using actual `<`/`>`/`&`.
- **edit tool intermittent "edits.0: must be object" errors:** the edit tool occasionally rejects a call with this validation error (a serialization hiccup). Just re-issue the identical call — it succeeds on retry.
- **slice-verifier is extremely adversarial** (budget 2-5 rounds per slice; this session: S1=3, S2=4, S3=2, S4=3, S5=2). Fix-and-re-dispatch on real findings; surface-and-proceed on pathological/by-design findings (ratify at the micro-checkpoint). The Slice 4 R1 round found **12 real issues** on the load-bearing installer — all worth fixing.
- **D15 per-release InstalledRecord (the cascade):** `InstalledRecord` is now a per-release schema-versioned document with `schema: 'radiprotocol.installed-record'` + `version: 1` sentinels. One file per installed release at `.radiprotocol/library/installed/<packageIdSlug>/<versionSlug>.json`. The file's **presence + validity + identity-match = the install commit marker** (written LAST by the installer; absence after an interrupt = rollback trigger). `InstalledRecordStore` exposes `read(packageId,version)`/`list()`/`write(record)`/`delete(packageId,version)` — NO shared index document, NO `readAll`/`writeAll`/`emptyRecords`.
- **Slice 4 installer invariants (load-bearing — carry into Slices 6-9's understanding):**
  - All I/O under a single module-level `installMutex` (`WriteMutex`, fixed key `'library-install'`), directly via `app.vault`/`adapter` — NEVER `InstalledRecordStore.write()`/`SnippetService.save()` mid-transaction. `writeJsonFile(vault, installMutex, path, ...)` is safe: the inner per-path key (`path`) differs from the outer key (`'library-install'`) → no async-mutex re-entrant deadlock.
  - **Validate-then-journal-then-commit:** `planInstall` validates entirely in memory (slugs → destination-free collision → manifest/content closure + .md-only + path-safety → SHA-256 integrity → parser → mapping → subfolder-closure → rewrite + dual-binding-reject + rewritten-path `assertNoTraversal` gate → re-parse → staged `GraphValidator` probe). Journal written BEFORE any final-path write; per-release marker written LAST.
  - **Never-throws:** `install()` wraps EVERYTHING (incl. `bundle.manifest` destructure) in try/catch → `{status:'failed'}`; post-commit journal removal is best-effort (a committed marker is NEVER rolled back). `recoverInterrupted()` catches `listAll` + per-journal failures.
  - **Rewritten-protocol hash:** the marker records `sha256String(JSON.stringify(rewrittenDoc, null, 2) + '\n')` (the INSTALLED rewritten doc's hash), NOT the source manifest hash — so the recorded hash matches the on-disk file. The manifest's `protocolSha256` is used ONLY for source integrity verification.
  - **Rollback safety:** `removeOwnedPaths` deletes only paths passing `assertNoTraversal(p) !== null && (p === markerPath || p.startsWith(protoNs+'/') || p.startsWith(snipNs+'/'))` — closes a `..`-traversal-past-prefix hole (`protoNs/../../user-file.md` is rejected by `assertNoTraversal`). Empty-folder cleanup only removes a dir when `adapter.list(dir)` confirms it is empty (never recursively deletes non-empty folders). Shared by `rollbackTransaction` (paths from journal entries) and `uninstall` (paths from the InstalledRecord).
  - **Reference rewrite:** targets the STORED node fields `fields.snippetPath`/`fields.subfolderPath` (camelCase, per `src/protocol/protocol-document.ts` `ProtocolNodeRecord.fields`), NOT the runtime `radiprotocol_snippetPath`. `buildReferenceMapping` is fed the PARSED runtime snippet nodes (`[...parsed.graph.nodes.values()].filter(n => n.kind === 'snippet')`). Extension-preserving (matches the stored `.rp.json` format).
  - **Staged validation probe:** `new GraphValidator({ snippetFileProbe: abs => plannedFinalPaths.has(abs), snippetFolderPath: settings.snippetFolderPath, t })`. `plannedFinalPaths` = `new Set(manifest.snippetFiles.map(f => librarySnippetFilePath(snippetRoot, packageId, version, f.relPath)))`. The validator composes `${snippetFolderPath}/${rewrittenRelPath}` and probes — matches `plannedFinalPaths`. A snippet node referencing a file NOT in the manifest → D-04 rejects (tested).
- **Malformed-journal skip in `TransactionJournalIO.listAll`** is **surface-and-proceeded** (ratified by verifier): recovery-on-load must be robust — one malformed journal must not block recovery of other in-flight transactions; a malformed journal has no usable owned-paths list (its orphaned paths live harmlessly under `library/<pkg>/<ver>/`, out of foundation recovery scope). I/O failures (adapter.list/read) DO surface as `LibraryStoreError('read-failed')` per D3; only JSON/schema corruption is skipped (per-file isolation, mirroring `InstalledRecordStore.list`).
- **No source files were modified** this session — everything lives in the design artifact. Repo still at commit `4ad002c` (only the untracked `.rpiv/artifacts/` files exist).
- **Scope discipline (unchanged):** foundation = read + install only. Do NOT implement submission wizard, auth, moderation, upgrades, ed25519 signature, reports/takedown. Manifest/service boundaries are forward-compatible but contain NO speculative fields for deferred features. SHA-256 = integrity, NOT authenticity — UI must never mark unsigned releases as "trusted" (only "integrity verified").
- **`DEFAULT_REGISTRY_URL = ''`** (Slice 2) — empty until the official registry domain is provisioned; empty/non-https/invalid → explicit "catalog unavailable" state, never a throw. Do NOT hard-code `https://registry.radiprotocol.org`.
