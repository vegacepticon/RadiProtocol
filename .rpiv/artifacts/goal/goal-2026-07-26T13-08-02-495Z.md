* I want to add the ability to create snippets while working through a protocol in the Runner, as well as directly through a command-line command. The Runner modal should include an icon that, when clicked after selecting some text, opens a modal similar to the one used when creating a snippet through the Snippet Editor. The selected text should already be inserted into the modal, so that I can add placeholders where needed, edit the text, and save the newly created snippet to the desired directory.

* When I run the **“Insert snippet”** command, a modal appears that allows me to select a snippet using either navigation or search. However, I do not like the way this modal “jumps” while I am searching for a snippet, as though it is constantly trying to recenter itself. I would prefer the modal to remain fixed near the top of the screen, with the list of matching results expanding downward or shrinking as the search query changes. This would be easier on the eyes, and the visual focus would remain on the modal.

  I would also like to be able to select a snippet using the arrow keys and insert it by pressing **Enter**, in addition to selecting it with the mouse.

  Currently, each snippet in this modal displays both its name and the path where it is stored. For convenience, I would prefer to display only the snippet name.
