* I want to remove the icon for creating a snippet from selected text. This icon is located in the Runner modal, to the right of the “X” icon used to close the Runner.

* I want to update the sections about “Existing Canvas Protocols” and “Snippets” in the README files. The old Canvas protocols are no longer used anywhere, so this information is only confusing. The same applies to snippets: we now use only `.md` snippets, which can contain placeholders or plain text. We no longer use the JSON format.

* I want to remove the “Text block” node type and have the “Answer” node perform the same function. For example, in a sequence such as `Question → Answer1 → Answer2`, the user selects `Answer1` because it comes directly after the `Question`, while `Answer2` is inserted automatically, similar to how the “Text block” node currently works. The goal is to reduce the number of node types to the minimum necessary and avoid having nodes with very similar or nearly duplicate functionality.

* I would like to discuss whether it is possible to find a good solution for the following task: I want to remove the “Loop” node type and move its functionality to the “Question” node. For example, there could be a checkbox or icon that turns a regular “Question” node into a looping question that allows the user to select multiple answers, similar to how the current “Loop” node works. It is important that configuring and using such nodes remains convenient and intuitive for the user.

* I want newly created protocols to include a “Start” node by default, so that users do not have to create it manually immediately after creating a protocol and can start building connections from it right away.

* I want the selected snippet in the modal opened by the `Insert Snippet` command to be highlighted more clearly. The current highlight color is too pale, so it is not always easy to see which snippet is selected when navigating with the keyboard arrow keys.

* I want to add a small margin between the top edge of the screen and the modal opened by the `Insert Snippet` command. Currently, the modal is positioned directly against the top edge of the screen, which is not very convenient. The modal could also be extended vertically toward the bottom of the screen, while leaving a small margin at the bottom. At the moment, it only occupies approximately half of the screen height.
